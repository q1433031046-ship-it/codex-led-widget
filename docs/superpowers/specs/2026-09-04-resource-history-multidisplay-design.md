# 额度悬浮窗资源、历史与多屏隔离设计

## 范围

本次只修改额度悬浮窗的资源占用、账号历史留存和多屏磁吸收起隔离。
Codex 主程序的消息提醒、聊天历史和其他外部功能不在本次范围内。

## 固定行为

- 不新增资源、扫描频率或省电相关设置项。
- 主额度数据继续以 60 秒为上限刷新。
- 模型用量扫描降为低频，并在统计页打开或悬浮窗移入且数据过期时按需刷新。
- 窗口隐藏、磁吸收起或视觉区域不可见时暂停动画渲染；恢复显示时补一帧后继续。
- 设置页和统计页隐藏超过固定空闲时间后销毁，重新打开时重建并恢复状态。

## 历史数据

当前历史文件按账号隔离，保留 400 天和最多 20,000 个采样点。现有投影会按当前额度周期的 `resetsAt` 过滤，因此旧周期虽然可能仍在文件中，却无法显示。本次将保留周期归档，并在统计页提供只读的历史周期视图；悬浮窗主图仍仅展示当前周期，避免跨周期混合坐标。

历史文件保存改为原子写入，避免异常退出时直接覆盖造成截断。迁移保持兼容，不删除已有账号历史。

## 多屏隔离

收起状态使用 Windows Electron 原生窗口形状，将窗口裁剪为当前显示器边缘的可见条带；展开、移动、切屏、DPI/工作区变化和重启时恢复或重算完整形状。边界基于所选显示器 `workArea`，兼容负坐标、任务栏和上下左右排列。若 API 不可用，安全降级并记录。

## 验收

- 新增纯逻辑测试覆盖动画休眠、低频刷新去重、历史周期投影、原子保存和窗口形状矩形。
- `pnpm test` 全量通过。
- 打包并覆盖安装后检查真实 `app.asar` 和运行版本。
- 记录修改前后工作集、私有内存和 5 秒累计 CPU，不将累计值误报为 CPU 百分比。
- 在真实双屏、不同缩放、负坐标、任务栏不同边缘、收起/展开/切屏/重启场景验收。
